# Domain Before After Gain Phase
▸ Engineering sign-off checklist
✓
All protected routes require authentication
requireStaffAuth guards every /api route that accesses patient data. 9 auth-guard tests verify 401 on unauthenticated requests.
✓
Clinical notes are immutable once signed
sign-notes endpoint only updates status='draft' rows. The encounter complete flow auto-signs before closing, preventing re-opening of notes.
✓
Critical results trigger staff escalation within 2 hours
POST /api/cron/escalate-results checks critical is_critical=true results unacknowledged for >2h, fires SMS, and inserts escalation_events row.
✓
Allergy–medication conflicts surface before prescribing
AllergyMedAlert component runs client-side tokenised cross-check on every keypress. Confirmed conflicts require explicit acknowledgement.
✓
Offline edits are durable across page reloads
IndexedDB outbox persists pending saves. Executor registry replays on reconnect. SyncStatusIndicator shows amber/red when edits are queued.
✓
Every new Supabase table has RLS + service_role grants
All Phase 4–8 migrations follow the New Table Checklist in CLAUDE.md: RLS enabled, staff-access policy, GRANT to authenticated + service_role.
✓
Correlation IDs flow through every log line
correlationId middleware runs before pino-http. x-correlation-id is echoed or generated per request and stamped in customProps.
✓
FHIR R4 Patient and Encounter resources are exportable
GET /api/fhir/Patient/:id and /api/fhir/Encounter/:id return conformant application/fhir+json with OperationOutcome on error.
✓
Tab navigation is bookmarkable and browser-back works
setActiveSection syncs ?tab= via history.replaceState. popstate listener restores section on browser back/forward. Initial load reads from URL.
✓
Key interactive elements are keyboard-accessible
Tab strip has role=tablist + role=tab + aria-selected. Progress dots are <button> elements. Skip-nav link visible on focus. <main id=main-content> anchor present.
✓
AI safety gates remain enforced
FORBIDDEN_PATTERNS scan applied before every AI-drafted patient message. AI urgency uses max(questionnaire_severity, ai_severity) — never downgrades a red flag.
✓
Calendar cache persists across Render restarts
syncCalendarCache upserts to Supabase calendar_event_cache. loadCache reads Supabase first; falls back to JSON file during first-deploy grace period.
